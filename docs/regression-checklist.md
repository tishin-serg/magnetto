# Регрессионный чек-лист Magnetto

## Назначение

Чек-лист фиксирует пользовательские функции бота и уровень их проверки перед
слиянием в `master`. CI не использует production-секреты и не обращается к
Telegram, TMDb, JacRed, qBittorrent, домашнему ПК или S3: внешние API заменены
локальными fake HTTP-серверами или mock-объектами.

Команды для локального запуска:

```powershell
.\mvnw.cmd -Dgroups=ui-regression test
.\mvnw.cmd -Dgroups=api-regression test
.\mvnw.cmd verify
```

## Матрица функций

| Функция | UI regression | API regression | Проверка после deploy |
| --- | --- | --- | --- |
| `/start`, главное меню и переходы | Кнопки и callback-контракты | Отправка сообщения через Telegram API | Открыть главное меню |
| Поиск фильма через TMDb inline | Результаты, карточки, роутинг и быстрый путь | Запрос TMDb, декодирование и timeout | Ввести название и дождаться подсказок |
| Защита от дубля inline-выбора | Повторный callback/chosen result не создаёт вторую заявку | Не требуется | Выбрать один результат и проверить одну карточку |
| Настройки скачивания | Размер, сиды, цель и callback-контракты | Не требуется | Открыть настройки, не сохраняя изменения |
| Подбор и подтверждение раздачи | Карточка, смена варианта, отмена, устаревшие и чужие callback | Не требуется | Найти одну небольшую раздачу без запуска загрузки |
| Цели VPS, домашний ПК и S3 | Три цели и понятный отказ для недоступной S3 | Конфигурационные контракты покрываются полным `verify` | Проверить наличие трёх целей |
| Список задач и управление | Статусы, pause/resume, refresh и возврат | qBittorrent pause/resume с fallback на stop/start при 404 | Открыть задачи и обновить список |
| VPS-медиатека | Навигация и cleanup-кнопки | Доставка, ссылки и cleanup покрываются полным `verify` | Открыть медиатеку без удаления |
| Home WebDAV-медиатека | Файл, ссылка, удаление, подтверждение и возврат | PROPFIND, пути, Range proxy, Basic auth, 206/404 | Открыть домашнюю медиатеку при доступном ПК |
| S3-медиатека | Список, файл, download, delete, confirm и возврат | ListObjects, newest-first и cleanup только внутри prefix | Открыть S3-медиатеку и получить свежую ссылку |
| Очистка медиатек | VPS/Home/S3 и подтверждение | Ограничения путей/prefix покрыты API и полным `verify` | Только проверить экран подтверждения |
| Magnet-ссылка и выбор файлов | Общий маршрут покрывается полным `verify` | Валидация magnet и qBittorrent API покрыты полным `verify` | Не входит в безопасный smoke без тестовой раздачи |
| Лимиты размера и повторные попытки | Предупреждения и подтверждение покрыты полным `verify` | Retry и size guard покрыты полным `verify` | Проверять отдельным тестовым torrent |
| Ссылки для iPhone/Infuse | Кнопки и подписи | Home download endpoint и Range | Открыть ссылку на тестовом файле |
| LLM-маршрутизация | Быстрые команды не уходят в LLM | Основной LLM router покрыт полным `verify` | Не входит в этот regression-набор |

## UI Regression

UI-набор проверяет Telegram-контракты без браузера: тексты, inline keyboard,
callback data, пагинацию, переходы назад, подтверждения и защиту от повторной
обработки. Это устойчивее скриншотных тестов для Telegram Web и ловит поломки,
из-за которых кнопка перестаёт вести в нужный handler.

Запуск помеченных тестов выполняется JUnit-тегом `ui-regression`.

## API Regression

API-набор поднимает локальные HTTP-серверы и проверяет реальные запросы и ответы:

- Telegram Bot API: `getUpdates`, параметры allowed updates и `sendMessage`;
- TMDb: параметры поиска, JSON и ограничение времени ответа;
- JacRed: structured search, fallback search и декодирование результатов;
- qBittorrent: управление torrent и совместимость pause/resume со start/stop;
- Home WebDAV: листинг, нормализация путей, авторизация и Range;
- download endpoint: токен, имя файла, `206 Partial Content` и `404`;
- S3: prefix медиатеки, сортировка newest-first и очистка только этого prefix.

## Ручной Smoke После Deploy

1. Отправить `/start`, проверить главное меню и раздел задач.
2. Ввести название фильма через inline-поиск и дождаться подсказок TMDb.
3. Выбрать фильм и один раз запустить поиск JacRed; должна появиться одна карточка.
4. Открыть настройки и убедиться, что доступны VPS, домашний ПК и S3.
5. Открыть VPS, Home и S3 медиатеки, если соответствующие сервисы включены.
6. На экране очистки дойти до подтверждения и отменить действие.

Фактическую загрузку, удаление или очистку production-хранилища не выполнять как
часть автоматического CI. Эти сценарии запускаются отдельно на подготовленном
маленьком torrent и тестовом объекте S3.

## Правило Слияния

Pull request в `master` должен иметь успешные checks `UI Regression`,
`API Regression` и `Test`. Job `Test` зависит от обоих regression-наборов, поэтому
полная сборка не начнётся при раннем падении пользовательского или API-контракта.
В настройках защиты `master` эти checks должны быть отмечены как required.
